Bonjour,

Plusieurs nouvelles fonctionnalités ont été déployées sur votre plateforme Bois&Co. Ce message vous présente ce qui a changé, qui est concerné, et comment en tirer parti dès maintenant.

Aucune action de votre part n'est requise pour accéder aux nouveautés — elles sont accessibles immédiatement depuis votre espace habituel.

Nouveau module
📊
Suivi DécomptesNouveau

Un module complet de suivi hebdomadaire des décomptes clients est désormais disponible dans la section Suivi Financier du menu latéral. Il fonctionne de façon totalement autonome — aucune saisie en double avec les projets existants.

  • Dashboard global — Vue d'ensemble de tous les projets en cours : Marché yc Avenants, Livraison Système, Reste à livrer/attacher, Cumul Règlements, Alerte Acompte.
  • Fiche projet — KPIs en temps réel, gestion des avenants, historique complet des lignes de décompte (Attachement, RG, RF, Prorata, Amortissement, Acompte, HT, TTC, Règlement, Liv. Système).
  • Saisie hebdomadaire — Formulaire de saisie des décomptes avec marquage automatique du « dernier décompte actif » par projet.
  • Import CSV — Migration de l'historique en une seule opération depuis votre fichier Excel existant (format multi-lignes, plusieurs décomptes par projet).
Améliorations
🥧
Dashboard COMEX — Visualisation graphiqueMis à jour

Les quatre sections « Répartition » du tableau COMEX peuvent maintenant basculer entre vue tableau et graphique camembert interactif, pour faciliter les présentations en réunion.

  • Répartition par Commercial, par Statut, par Segment, par Ville.
  • Boutons Tableau / Graphique en haut de chaque section.
  • Ligne TOTAL ajoutée dans les tableaux Statut, Segment et Analyse Géographique.
📥
Import CSV PipelineMis à jour

Les Directeurs Commerciaux peuvent désormais importer des opportunités pipeline en masse depuis un fichier CSV, avec validation automatique des commerciaux, des statuts et des probabilités.

  • Bouton « Importer CSV » disponible sur la page Analyse Pipeline.
  • Rapport détaillé après import : lignes créées / ignorées avec motif.

Pour l'équipe ADV — Migration des données historiques :
Si vous souhaitez importer votre historique de décomptes depuis Excel, exportez votre fichier en CSV avec séparateur point-virgule (;) puis utilisez la fonction Import CSV dans le menu Suivi Financier. Le système accepte plusieurs lignes de décomptes par projet sur le même fichier. En cas de doute sur le format, contactez l'administrateur avant d'importer.
