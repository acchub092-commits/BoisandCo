Format du fichier CSV

Séparateur ; — encodage UTF-8 ou Windows-1252. Structure multi-lignes : une ligne par décompte. Plusieurs lignes peuvent appartenir au même projet — la première ligne contient les infos projet, les suivantes (avec la colonne Projet vide) sont les décomptes historiques du même projet.

{# Avertissement re-import #}
⚠ Un import remplace toutes les lignes décompte existantes pour chaque projet trouvé. Utilisez cette fonction uniquement pour la migration initiale des données.
Colonne CSV Obligatoire Description
Colonnes BLEUES — infos projet (1ère ligne uniquement)
ClientNon*Nom du client (utilisé si Projet introuvable)
ProjetOuiNom exact du projet dans le système (ex: WELIVE)
AdjudicationNonOUI / NON
CommercialNonPrénom du commercial (doit correspondre à un compte actif)
LotNonLibellé du lot (ex: MNB)
RégimeNonAvec TVA / Sans TVA
Montant Marché HTNonMontant initial du marché HT (MAD) → mis à jour sur le projet
AvenantsNonMontant total des avenants → crée un DecompteAvenant si non vide
Chef de ProjetNonPrénom du chef de projet (doit correspondre à un compte actif)
Colonnes VERTES — données décompte (1 ligne = 1 décompte)
ATTACHEMENTNonCumul attachement à date de ce décompte (MAD)
PRORATANonProrata
RGNonRetenue de Garantie
RFNonRetenue de bonne Fin
AUTRENonAutre retenue
AMORTISSEMENT D'ACOMPTENonAmortissement d'acompte
ACOMPTENonAcompte versé au projet
Type OpérationNonDécompte / Situation / Facture / Avoir
N° DécompteNonNuméro de décompte
HTNonMontant HT net facturé de ce décompte
Réf. PièceNonRéférence pièce comptable
Date édition factureNonFormat M/J/AAAA (ex: 2/9/2026 = 9 février 2026)
REGLEMENTNonRèglement reçu pour ce décompte
LIV SYSTÈMENonLivraison système cumul à date
Colonnes IGNORÉES (calculées automatiquement)
Marché yc Avenants—Calculé = Montant Marché HT + Avenants
TTC—Calculé = HT × 1.20 si Avec TVA
ALERTE ACOMPTE—Calculé = Acompte − Amortissement
CUMUL REGLEMENTS—Calculé sur le dernier décompte
RESTE A LIVRER—Calculé = Marché yc Av. − Liv Système
RESTE A ATTACHER—Calculé = Liv Système − Attachement

* La recherche se fait d'abord par Projet (nom exact), puis par Client si introuvable. La dernière ligne de décompte par projet est automatiquement marquée comme « Dernier décompte actif ».
