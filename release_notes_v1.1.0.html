Tableau de bord COMEX — Pipeline commercial
Nouveau
GET /crm/comex/

Nouvelle page de synthèse pipeline à destination de la Direction et du Comité Exécutif. Toutes les données sont calculées dynamiquement depuis le modèle Lead en temps réel. La page est imprimable (bouton Imprimer, CSS @print intégré).

  • Bannière KPI : Pipeline total, Pipeline pondéré, Projets actifs, Alertes à corriger, HIGH Priority
  • Répartition par Commercial : projets actifs, potentiel, % pipeline, pondéré, H.Priority — avec ligne TOTAL
  • Répartition par Statut : Prospection / En cours / Négociation / Gagné / Perdu
  • Répartition par Segment : Residential, Commercial, Hospitality, Institutional, Industrial & Logistics
  • Analyse géographique : Top 12 villes par potentiel
  • Top 10 Projets : classés par montant pondéré, avec badges d'alerte individuels
  • Dépendance Commerciale : barre visuelle, signal coloré (OK / Watch / Danger si > 50%)
  • Pilotage Temporel : buckets 0–30 j / 30–90 j / +90 j / Dépassé + couverture en mois
  • Synthèse Alertes : SANS ACTION / 80%+ SANS ACTION / INCOHÉRENT / MONTANT VIDE / PROB MANQUANTE
  • Liste détaillée des alertes : 50 premières, avec lien direct vers le lead
DIRECTEUR MANAGER ADMIN
Détails techniques
  • Vue COMEXDashboardView — un seul queryset select_related, tous les calculs en Python
  • Pondération : LOW → 10 %, MED → 50 %, HIGH → 80 %, GAGNEE → 100 %
  • Lien sidebar "Tableau COMEX" ajouté pour les rôles autorisés

Import en masse de leads — Pipeline CRM
Nouveau
GET / POST /crm/import/

Interface d'import CSV par glisser-déposer permettant d'injecter en masse des leads dans le pipeline commercial. Deux formats sont auto-détectés : le format DC (export Excel du Directeur Commercial) et le format canevas interne.

  • Drag & Drop : zone d'upload interactive avec Alpine.js
  • Détection automatique de format : export Excel DC ou canevas standard
  • Mapping statut : Prospection → VISITE, En cours → CHIFFRAGE, Négociation → OFFRE, Gagné / Perdu
  • Mapping probabilité : 0–10 % → LOW, 50 % → MED, 80–100 % → HIGH
  • Encodages acceptés : utf-8-sig, utf-8, latin-1, cp1252
  • Rapport d'import : lignes créées / ignorées / erreurs détaillées en session
  • Téléchargement du canevas vierge : bouton "Télécharger le canevas" → CSV prêt à remplir
  • Prénoms reconnus : affichage des commerciaux disponibles dans la base
  • Bouton pipeline : "Import en masse" visible dans la topbar pour DIRECTEUR / MANAGER / ADMIN
DIRECTEUR MANAGER ADMIN
Détails techniques
  • Vue ImportLeadsView — GET affiche le formulaire, POST traite le fichier
  • Commande CLI complémentaire : python manage.py import_leads fichier.csv --dry-run
  • Action ?action=template sert le CSV canevas en téléchargement direct

Formatage français des montants — Séparateur de milliers
Amélioration

Tous les montants en MAD dans les tableaux de bord CRM et COMEX utilisent désormais l'espace comme séparateur de milliers (format français). Ex : 723 669 016 MAD au lieu de 723669016.

  • Filtre Django sep_milliers : créé dans apps/crm/templatetags/crm_filters.py
  • Appliqué sur : tous les montants MAD du tableau COMEX (pipeline, pondéré, commercial, segments, villes, top 10…)
  • Appliqué sur : budget "Top opportunités" et colonne "Pipeline" du Dashboard CRM
  • Enregistré explicitement dans settings.py → TEMPLATES.OPTIONS.libraries pour garantie de disponibilité

Filtres Commercial & Méthodiste — Dashboard Chiffrage
Nouveau
GET /chiffrage/?commercial=<id>&methodiste=<id>

La barre de filtre du dashboard Chiffrage s'enrichit de deux nouveaux selects permettant de filtrer les demandes par commercial émetteur et par méthodiste assigné. Ces filtres sont visibles uniquement pour les rôles ayant une vue globale.

  • Filtre Commercial : select dynamique alimenté par les utilisateurs rôle COMMERCIAL
  • Filtre Méthodiste : select dynamique alimenté par les rôles RESP_METHODES et ESTIMATEUR
  • Soumission automatique à la sélection (onchange)
  • Intégrés dans la condition "Réinitialiser" et le message "Aucun résultat"
  • Masqués pour les commerciaux (ils ne voient que leurs propres demandes)
DIRECTEUR MANAGER RESP_METHODES ESTIMATEUR ADMIN
Détails techniques
  • Filtres DB : filter(commercial_id=...) et filter(assigned_to_id=...)
  • Paramètre can_filter_people transmis au template pour contrôle d'affichage conditionnel

Suppression de documents — Fiche Chiffrage
Nouveau
POST /chiffrage/<pk>/fichier/<fichier_pk>/supprimer/

Les administrateurs peuvent désormais supprimer un document attaché à une demande de chiffrage directement depuis la fiche, sans passer par l'interface d'administration Django. La suppression est physique (fichier et entrée base de données).

  • Bouton Supprimer en rouge, affiché à côté du bouton "Télécharger" pour chaque fichier
  • Confirmation native du navigateur avant suppression définitive
  • Suppression physique du fichier sur le disque + entrée en base de données
  • Action journalisée dans l'historique de la demande (« Fichier supprimé : nom »)
  • Message de confirmation affiché après suppression réussie
ADMIN uniquement Superuser
Détails techniques
  • Vue FichierDeleteView — POST uniquement, lève PermissionDenied si rôle insuffisant
  • Appel fichier.fichier.delete(save=False) pour suppression physique avant fichier.delete()
